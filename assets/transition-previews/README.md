# Transition preview assets

This directory contains 21 lightweight MP4 preview clips and 21 matching poster JPGs for the Montazhnaya_1 transition library. The project maintainer confirms that the original transition demonstration videos were generated by the maintainer with Grok using a paid consumer subscription. The MP4s here are preview derivatives prepared for hover playback: 640×360, 20 fps, silent H.264. Poster JPGs are still frames extracted from the corresponding previews.

**Attribution required by the Grok Brand Guidelines: Created with Grok.** This attribution also appears in the repository-level `ASSET_CREDITS.md` and the application's Help → About dialog. Any watermark present in the source output must remain intact; no new watermark is added by this repository. These preview videos and poster images are licensed separately from the application code under **CC BY 4.0**; see `../../ASSET_LICENSE.md`. The maintainer prepared the preview trims/re-encodes and extracted the poster frames.
