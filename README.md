## What is Montazhnaya?

Montazhnaya_1 is an independent desktop video editor for assembling video, images and audio on a local Windows PC. It grew out of a practical need for an accessible editing tool without a mandatory expensive subscription. It is a community beta, not a claim to replace mature professional editing suites.

The original application source code and project documentation are released under **GNU General Public License v3.0 or later (GPL-3.0-or-later)**.

## Current feature set

- Multi-track timeline for video, images and audio.
- Video, still-image and audio import.
- Drag-and-drop media workflow and numbered media arrangement.
- Project preview and clip parameter controls.
- Transition library with 21 animated demonstration previews and posters, including the procedural WebGL2 **Fire Whirl** transition. The original demo videos were generated by the project maintainer with Grok; attribution is included in the app and documentation.
- Clip splitting and playback speed controls from 0.25× to 4×.
- MP4 export with H.264/AAC and WebM export with VP8/VP9 + Opus, subject to the installed FFmpeg build.
- Frame-grid export, FFprobe validation and runtime checks for available encoders.
- 36 interface language variants. Russian and English are the reference interfaces; the other 34 language packs are machine-assisted drafts and need fluent-speaker review.

Hardware encoders (NVIDIA NVENC, AMD AMF and Intel Quick Sync) are probed at runtime. Availability and performance depend on the installed FFmpeg build, GPU, driver and Windows environment. A passing automated test does not certify every physical GPU.

## What it is — and is not

Montazhnaya_1 remains a beta intended for testing and smaller editing tasks. It is not presented as a replacement for Adobe Premiere Pro, DaVinci Resolve or other mature editors. Export speed, supported source formats, GPU compatibility and UI behavior can vary by hardware and media. Please report reproducible issues and include Windows version, CPU/GPU, driver, sample-media details and export settings where possible.

## Development environment

- Windows 10/11 x64 is the primary target.
- Node.js 22.12.0 or newer; Node.js 24 LTS is recommended.
- Electron is pinned in `package.json` and `package-lock.json`.
- FFmpeg and FFprobe are external tools and are **not bundled** in the Windows release. Configure `FFMPEG_PATH` / `FFPROBE_PATH` or install compatible tools separately.
