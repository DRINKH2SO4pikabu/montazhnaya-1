## О проекте

Montazhnaya_1 — независимый настольный видеоредактор для Windows, предназначенный для монтажа видео, фотографий и звука на локальном компьютере. Проект вырос из практической задачи: хотелось иметь доступный инструмент для монтажа без обязательной дорогой подписки.

Это открытый проект и Beta-версия. Мы не выдаём её за готовую замену профессиональным монтажным комплексам. Исходный код приложения и документация распространяются по **GNU GPL-3.0-or-later**.

## Что уже реализовано

- Многодорожечный таймлайн для видео, изображений и аудио.
- Импорт видео, фотографий и аудиофайлов.
- Перетаскивание медиа на таймлайн и расстановка по нумерации файлов.
- Предварительный просмотр проекта и настройка параметров клипов.
- Библиотека переходов с 21 анимированным демонстрационным роликом и постером, включая процедурный WebGL2-переход **Fire Whirl**. Исходные демонстрационные видео созданы сопровождающим проекта с помощью Grok; атрибуция сохранена в программе и документации.
- Разделение клипов и изменение скорости воспроизведения от 0,25× до 4×.
- Экспорт MP4 с H.264/AAC и WebM с VP8/VP9 + Opus — в зависимости от установленной сборки FFmpeg.
- Экспорт по точной кадровой сетке, проверка результата через FFprobe и runtime-проверка доступных кодировщиков.
- 36 вариантов интерфейса. Русский и английский — основные языки; остальные 34 языковых пакета являются машинно-ассистированными черновиками и нуждаются в вычитке носителями.

Аппаратные кодировщики NVIDIA NVENC, AMD AMF и Intel Quick Sync проходят проверку доступности при запуске. Фактическая работа зависит от видеокарты, драйвера, версии FFmpeg и конфигурации Windows. Успешные автоматические тесты не означают, что проверены все модели GPU.

## Что проверено для релиза 3.6.45 Beta

Сборка выполнена GitHub Actions на Windows x64 runner. Релизный workflow успешно завершил:

- Проверку lock-файлов, SRI и `npm audit` для зависимостей приложения и инструментария Windows-сборки.
- Проверку версии Electron runtime.
- QA локализаций и полный набор регрессионных тестов — **435 тестов прошли**.
- Создание CycloneDX SBOM для зависимостей приложения и отдельный SBOM для Windows release-toolchain.
- Проверку лицензий проекта, а также Electron/Chromium notices внутри упакованного приложения.
- Тихую установку Setup, запуск установленной программы и отдельный запуск Portable.
- Генерацию SHA-256 для обоих EXE и общего файла контрольных сумм.
- Полный Gitleaks-скан истории Git.

В релиз приложены Setup, Portable, отдельные файлы контрольных сумм, общий `SHA256SUMS.txt`, оба SBOM, метаданные сборки и отчёт проверки пакета. Эти проверки подтверждают прохождение автоматизированного release-gate, но не являются сертификацией каждой версии Windows, каждого формата видео или каждой видеокарты.

## Ограничения Beta

Montazhnaya_1 пока рассчитана на тестирование и небольшие задачи монтажа. Это не замена Adobe Premiere Pro, DaVinci Resolve или другим зрелым профессиональным редакторам. Скорость экспорта, поддержка исходных форматов, работа GPU и поведение интерфейса зависят от компьютера и медиафайлов.

Пожалуйста, сообщайте о воспроизводимых ошибках через [GitHub Issues](https://github.com/DRINKH2SO4pikabu/montazhnaya-1/issues). По возможности указывайте версию Windows, процессор, видеокарту, драйвер, параметры исходных файлов и настройки экспорта.

## Системные требования и инструменты

- Windows 10/11 x64.
- FFmpeg и FFprobe не входят в сборку. Установите совместимую версию отдельно и настройте `PATH`, `FFMPEG_PATH` и `FFPROBE_PATH`.
- Для разработки: Node.js 22.12.0 или новее; рекомендуется Node.js 24 LTS.

Инструкции по сборке: [BUILDING_RU.md](BUILDING_RU.md). Журнал проверок и оставшиеся задачи по совместимости оборудования: [PUBLICATION_READINESS_RU.md](PUBLICATION_READINESS_RU.md).
