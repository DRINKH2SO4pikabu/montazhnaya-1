# Montazhnaya locale packs — beta 3.6.44

The renderer uses local UTF-8 JavaScript language packs. No network translation service is required at runtime.

## Available languages

- `ru` — Russian source language.
- `en` — English reference pack (436 source strings).
- `international.js` — 24 international preview locales: `de`, `fr`, `es`, `pt-BR`, `it`, `pl`, `uk`, `tr`, `zh-CN`, `zh-TW`, `ja`, `ko`, `ar`, `he`, `hi`, `nl`, `sv`, `fi`, `cs`, `ro`, `el`, `vi`, `id`, `th`.
- `cis.js` — 10 regional preview variants: `kk` Kazakh, `uz` Uzbek (Latin), `uz-Cyrl` Uzbek (Cyrillic), `ka` Georgian, `hy` Armenian, `tk` Turkmen, `az` Azerbaijani, `ky` Kyrgyz, `tg` Tajik and `be` Belarusian.

There are 34 preview language variants in addition to Russian and English (36 selectable options overall).

## Coverage in beta 3.6.44

The 24 international preview packs contain draft translations for all 436 English reference keys and have no English fallback entries.

Nine regional language packs — Kazakh (`kk`), Uzbek Latin (`uz`), Azerbaijani (`az`), Georgian (`ka`), Armenian (`hy`), Turkmen (`tk`), Kyrgyz (`ky`), Tajik (`tg`) and Belarusian (`be`) — now map all 436 source keys with zero English fallback. The regional dictionaries include editing operations, clip properties, transforms, color correction, titles, audio controls, slideshow workflows, diagnostics, warnings, recovery messages and long-form help.

Uzbek Cyrillic (`uz-Cyrl`) is a separate selectable script variant and maps all 436 source keys. Its text is generated by deterministic transliteration from the Uzbek Latin draft; it is **not an independent Uzbek Cyrillic translation** and is explicitly marked `transliteration-draft` pending review by a native Uzbek speaker.

The 24 international packs plus 10 regional variants provide 34 preview choices; Russian and English bring the total to 36 selectable options. Source-key coverage is not the same as native-speaker approval: all translations remain drafts, and dynamically composed UI strings outside the reference dictionary may still need localization.

## Language detection and scripts

BCP-47 tags resolve by exact locale, script subtag, or primary language: `kk-KZ` → `kk`, `uz-UZ` → `uz`, `uz-Cyrl-UZ` → `uz-Cyrl`, `ka-GE` → `ka`, `hy-AM` → `hy`, `tk-TM` → `tk`, `az-AZ` → `az`, `ky-KG` → `ky`, `tg-TJ` → `tg` and `be-BY` → `be`.

Arabic (`ar`) and Hebrew (`he`) remain RTL. Uzbek Latin and Cyrillic use the system Latin/Cyrillic font fallback stacks. Georgian and Armenian have script-aware font fallbacks. Font stacks are declarations, not confirmation that every target Windows installation has identical fonts installed.

## Electron IPC error messages — beta 3.6.45 Stage 5

The renderer loads `ipc-error-translations.js` after `notifications.js` and before `i18n.js`. The registry provides 30 keyed messages for each of the 34 preview locales. Once a language pack is loaded, `MontazhnayaNotificationCatalog.augmentLocale(locale)` copies the matching keyed messages into that locale's semantic catalogue. The main process still returns only stable error codes, semantic keys and bounded scalar parameters; it does not send display-ready prose.

All 1,020 translations are machine-assisted drafts. Placeholder integrity and runtime catalogue insertion are automated, but native-speaker linguistic review and visual review of real Electron dialogs remain required. Run `npm run qa:locales` to validate the registry and its placeholders.

## Stage 10 — detailed-tooltip terminology consistency

The detailed-tooltip catalogue now uses the same Ripple Delete command wording as the existing editorial UI glossary in all 30 locales that have an editorial glossary entry. The four CJK locales keep their native locale-specific command labels; their instruction text is checked against the same title. Only the Ripple Delete title and its immediately related instruction fragment were changed in affected packs; the 364-entry pack size and translation metadata remain intact.

The audit script qa/audit-tooltip-ripple-terminology.cjs validates all 34 preview locales and writes qa/ripple-delete-tooltip-terminology-stage10.md. It is part of npm run qa:locales. The test suite also contains a regression test so future translation updates cannot reintroduce the old English/mixed command label or diverge from the editorial glossary.

These are machine-assisted terminology harmonizations, not native-speaker approvals. All 34 preview languages still require fluent-speaker review.

The dedicated audit `qa/audit-detailed-tooltip-locales.cjs` checks all 364 detailed tooltip fragments across the 34 preview locales. It verifies that every pack registers, that no translation is missing or empty, and that interpolation placeholders match the English reference. It also records possible losses of file extensions, codec/platform identifiers, format labels, keyboard shortcuts and editor command names for manual review. Run `npm run qa:locales` to generate `qa/detailed-tooltip-quality-audit.md` and its JSON companion. Protected-token findings are review candidates rather than automatic failures because some terminology can be legitimately localized.

The detailed-tooltip audit also counts exact unchanged matches to the Russian source text and reports Cyrillic characters appearing in locales that do not normally use Cyrillic. It also fails the test suite if any preview fragment remains exactly equal to the English reference: the current catalogue has zero exact English matches across all 12,376 preview translation cells. The immutable technical-token check is deliberately limited to file extensions, codec/container/platform identifiers and resolution labels; localized keyboard names and units such as FPS and Mbps are not treated as missing tokens. Exact Russian-source matches fail the focused regression test; unexpected script mixing remains a review candidate so valid loanwords or isolated glyphs can be judged in context. The four CJK language labels for Ripple Delete are preserved in their native forms, while the other 30 preview locales must match the editorial tooltip glossary.
This audit is structural and technical only. It does not certify grammar, naturalness, regional terminology or accessibility. All 34 preview packs remain machine-assisted drafts pending native-speaker review; `uz-Cyrl` remains a transliteration-derived draft requiring independent review.
