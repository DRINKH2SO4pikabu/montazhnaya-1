# QA — Montazhnaya beta 3.6.8

## Автоматические проверки

- [x] Оценка PNG меняется пропорционально размерам canvas и числу кадров.
- [x] Валидация граничных значений width/height/FPS/duration/WAV bytes.
- [x] Учет временного и целевого томов.
- [x] Совмещение потребностей, если оба каталога на одном томе.
- [x] Отдельная блокировка при дефиците места на целевом томе.
- [x] Предупреждение между ожидаемым и консервативным запасом, без ложного жёсткого отказа.
- [x] Предупреждение о внутреннем PNG-лимите 2 ГиБ.
- [x] Runtime-расчет оставшихся выходных кадров, исходных кадров, WAV, временного MP4 и финальной копии.
- [x] Реальный запрос свободного места через `fs.promises.statfs`.
- [x] Подмена файловой системы в тесте.
- [x] Renderer передаёт размеры выходного canvas и точный размер WAV.
- [x] Main выполняет preflight, контроль во время генерации и проверку точного размера перед копированием.

## Результаты

- `npm.cmd test` (Node test runner): 87/87 — PASS.
- `node --check electron/main.cjs`: PASS.
- `node --check electron/preload.cjs`: PASS.
- `node --check electron/disk-space.cjs`: PASS.
- Встроенный JS Renderer: синтаксис проверен отдельно.
- `fs.promises.statfs(os.tmpdir())`: вернул доступное свободное место и идентификатор тома в текущей среде.

## Не проверено

- Запуск установщика в Windows PowerShell 5.1.
- Реальные диалоги предупреждения/блокировки в Electron GUI пользователя.
- Изменение свободного места на протяжении длительного экспорта на Windows/NTFS.
- Физическое исчерпание диска (проверяется логикой на mock-значениях, не заполнением пользовательского диска).
- Реальные экспортные тесты 4K/60 FPS, многослойного видео и длинных WAV на компьютере пользователя.
