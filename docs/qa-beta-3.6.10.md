# QA — «Монтажная» beta 3.6.10

## Исходная версия

- Полный пользовательский архив: beta 3.6.9.
- Проверка исходного набора до изменений: 101/101 тестов (подтверждено скриншотом пользователя и повторным локальным прогоном на полученном архиве).

## Итог после изменений

- Полный набор: **113 тестов, 113 passed, 0 failed, 0 skipped**.
- Node.js: 22.16.0 в рабочем окружении.
- FFmpeg/ffprobe: 7.1.5 в рабочем окружении.
- Синтаксис: `electron/main.cjs`, `electron/preload.cjs`, `electron/frame-sequence.cjs`, `electron/source-frame-cache.cjs`, `electron/disk-space.cjs` проверен через `node --check`.

## Конкретные интеграционные проверки

1. Полный CFR reference против ленивого окна: кадры совпадают по SHA-256 при 24, 25, 30 и 60 FPS.
2. Смещение `videoStream.start_time = 0.5s`: ленивый seek возвращает тот же PNG, что и full decode.
3. Окна у начала/середины/конца семисекундного H.264 тестового ролика корректны; число выходных PNG соответствует запросу.
4. Sparse plans не включают distant timeline ranges в одно окно, если они выходят за временной span.
5. Дисковая оценка pending source window резервирует raw RGBA + overhead.
6. LRU-очистка выбирает least-recently-used записи и поддерживает общий лимит 512 МиБ.
7. Renderer decoded-image cache учитывает декодированные байты, использует бюджет 256 МиБ и не удерживает одиночный сверхбюджетный кадр.
8. Исходное видео больше 128 МиБ по-прежнему декодируется по файловому пути; streaming MP4 и отмена FFmpeg остаются покрыты реальными FFmpeg-тестами.

## Не проверено в этой среде

- Запуск установщика в Windows PowerShell 5.1.
- Ручной экспорт из Electron GUI на Windows.
- Длительный многослойный 4K60 проект на компьютере пользователя.
- Повторный произвольный seek в большом VFR-источнике с нестандартным edit list.

## Критерий выпуска

Патч готов к контролируемой установке на пользовательскую beta 3.6.9. После установки обязательны `npm.cmd test`, короткий export с одним видеоисточником, экспорт с двумя видеослоями и повторный доступ к кадру, который был вытеснен из disk LRU.
