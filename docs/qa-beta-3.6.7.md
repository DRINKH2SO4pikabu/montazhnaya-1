## Автотесты

Команда:

```powershell
node --test tests/*.test.cjs
```

Результат в рабочей среде: **74/74 теста пройдены**. Включая прежние регрессионные тесты, тесты нового диагностического модуля и реальное двухвариантное кодирование короткого MP4 с проверкой через ffprobe.

## Реальная среда теста

- Платформа рабочей среды: Linux.
- FFmpeg: 7.1.5.
- ffprobe: 7.1.5.
- Кодирование: H.264 (`libx264`) и AAC.
- Контейнер: MP4.
- Диагностические тест-файлы: 64×64, 2 FPS, 1 секунда; временные файлы удаляются.

## Что ещё требует ручной приёмки на Windows

1. Запустить «Монтажную» beta 3.6.7.
2. Открыть «Справка» → «Диагностика FFmpeg и ffprobe…».
3. Убедиться, что видны пути и версии ffmpeg.exe/ffprobe.exe, если они доступны в PATH.
4. Убедиться, что H.264, AAC, MP4 и PNG отображаются как доступные.
5. Дождаться двух тестов: видео без звука и видео с AAC.
6. Для негативного сценария временно исключить папку FFmpeg из PATH либо указать несуществующий путь в переменной `FFMPEG_PATH`, перезапустить приложение и нажать «Проверить снова». После теста вернуть PATH.
7. Если используется `FFMPEG_PATH`/`FFPROBE_PATH`, убедиться, что сам экспорт тоже использует эти пути.

До ручной приёмки на Windows нельзя считать GUI-диагностику подтверждённой на пользовательской машине.
