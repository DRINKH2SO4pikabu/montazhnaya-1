# «Монтажная» beta 3.6.18 — битрейт, BT.709 и диагностика скорости экспорта

## Назначение

Точечное обновление локального потокового экспорта MP4/WebM. Цель — связать настройки качества в интерфейсе с фактическими параметрами FFmpeg, согласовать преобразование цвета и сделать узкие места длительного экспорта измеримыми.

## Что изменено

### 1. Управление средним битрейтом

- Выбранный в интерфейсе целевой битрейт теперь передаётся через IPC в главный процесс и далее в FFmpeg.
- MP4 H.264 использует средний режим `-b:v`; прежний фиксированный CRF 23 удалён из этого пути, потому что он игнорировал выбранную пользователем скорость потока.
- Для ограничения кратковременных пиков задаются VBV `-maxrate` около 125% целевого значения и `-bufsize` около двух секунд целевого потока.
- WebM VP8/VP9 получает ту же целевую скорость и ограничение пика.
- Настройка валидируется в диапазоне 0,25–100 Мбит/с. Отчёт ffprobe включает фактический битрейт видеопотока; результат отклоняется, если измеренное значение выше 160% цели. Фактическое среднее может быть ниже целевого на простом статичном материале.

### 2. Цветовой тракт BT.709

- PNG-кадры Canvas трактуются как RGB/sRGB, полный диапазон.
- Перед кодированием применяется явное преобразование sRGB transfer characteristic в BT.709, из RGB/GbR в YUV BT.709 limited-range, формат `yuv420p`.
- Для MP4 и WebM выставляются и проверяются четыре цветовых атрибута: `color_range=tv`, `color_primaries=bt709`, `color_trc=bt709`, `colorspace=bt709`.
- Проверка результата через ffprobe теперь учитывает не только матрицу и диапазон, но также передаточную характеристику и цветовые примарии.

### 3. Производительность и диагностика 4K/60 FPS

- Входная очередь image2pipe увеличена с 2 до 8 пакетов/кадров, оставаясь ограниченной.
- Кодировщик использует автоматический выбор числа рабочих потоков FFmpeg вместо фиксированных двух потоков.
- В экспорт добавлены замеры этапов: подготовка плана исходных кадров, чтение/декодирование источников, композиция Canvas, кодирование PNG, передача через IPC/backpressure, время работы FFmpeg и общее время операции.
- Сводка этапов показывается в статусе завершения экспорта, а детальная запись попадает в консоль разработчика.
- Это даёт данные, чтобы локализовать ограничение на конкретном компьютере. Ускорение полного 4K/60 проекта не заявляется без измерения на Windows-машине пользователя: отрисовка/PNG/IPC могут оставаться главным ограничением.

## Что не менялось

- Модель клипов, дорожки, таймкоды, слайд-шоу и переходы.
- Логика точного выбора исходных кадров.
- Отдельное офлайн-сведение аудио и мультиплексирование AAC/Opus.
- UI таймлайна и существующие проекты.

## Установка

Патч `Montazhnaya_Update_3.6.17_to_3.6.18_Bitrate_BT709_Performance_R1.zip` предназначен для beta 3.6.17.

1. Закрой «Монтажную».
2. Распакуй архив и запусти `INSTALL_UPDATE_3_6_17_TO_3_6_18.bat`.
3. Укажи корневую папку проекта, в которой находится `package.json` версии 3.6.17.
4. Установщик делает резервную копию каждого заменяемого файла в `backups/update-3.6.18-...`, сверяет SHA-256 скопированных файлов и выполняет откат при ошибке.
5. После установки из корня проекта выполни `npm.cmd test`.

Оригинальный архив и исходная папка проекта не перезаписываются автоматически; резервная копия остаётся доступной для ручного возврата.
