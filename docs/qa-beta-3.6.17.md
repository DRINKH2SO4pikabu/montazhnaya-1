# QA — «Монтажная» beta 3.6.17

## Объём

Промежуточный патч интерфейса поверх beta 3.6.16: стили native select, состояния enabled/disabled, отображение профиля проекта, сохранение нестандартных параметров при загрузке и при смене соотношения сторон.

## Автоматические проверки

Результат полного набора: **169/169 PASS**, 0 fail, 0 skipped.

Новый файл `tests/project-settings-ui.test.cjs` проверяет:

- тёмную цветовую схему нативного списка и контраст текста;
- отдельное оформление отключённых select/option;
- наличие видимого индикатора разрешения и FPS;
- сохранение нестандартного разрешения и нестандартного FPS при загрузке;
- подбор близкого по длинной стороне пресета при смене ориентации;
- отсутствие изменения клипов, времени маркеров и позиции курсора при смене профиля.

Существующие тесты версии обновлены до 3.6.17. Полный результат тестового набора записывается в релизной проверке после сборки пакета.

## Ручная проверка, требуемая на Windows/Electron

1. Открыть beta 3.6.17 и раскрыть FPS, Формат и Размер. Пункты должны быть читаемыми на тёмном фоне; выбранный и отключённый пункты визуально различимы.
2. Создать проект 16:9, 1920×1080, 30 FPS. В предпросмотре должен отображаться индикатор `1920 × 1080 · 30 FPS`.
3. Добавить несколько клипов и маркер, поставить курсор не на целую секунду, поменять FPS. Клип-таймкоды, длительности и время маркера не должны переписываться; курсор остаётся на прежнем времени.
4. Поменять формат 16:9 на 9:16. Выбранный пресет должен сохранить близкий класс разрешения (1920×1080 → 1080×1920), а не сбрасывать проект в минимальный HD.
5. Вернуть 16:9, затем нажать Undo и Redo. Параметры проекта должны восстановиться вместе с текущей историей.
6. Открыть сохранённый проект с нестандартным разрешением/FPS (если есть). Значения должны отображаться как «Пользовательский», а не заменяться молча стандартными.

## Ограничения проверки

Автоматические тесты подтверждают DOM/CSS-правила и сохранение модели проекта. Нативный popup `<select>` зависит от Chromium/Electron и Windows; окончательная оценка его внешнего вида выполняется на целевой Windows-машине.
