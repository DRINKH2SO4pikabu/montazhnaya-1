# Предварительный технический аудит — beta 3.6.21

Дата фиксации: 2026-11-02
Основа: восстановленная рабочая копия beta 3.6.20, последовательно обновлённая до 3.6.21. См. `RECONSTRUCTION_PROVENANCE.md`.

> Это первичный аудит исходников и тестируемой среды, а не полный аудит безопасности, лицензий или реального Windows/GPU-оборудования.

## Проверенная архитектура

| Компонент | Фактическая роль |
|---|---|
| `electron/main.cjs` | Главный процесс Electron; IPC, управление локальным FFmpeg/FFprobe, экспортные сессии, валидация результата и дискового пространства. |
| `electron/preload.cjs` | Узкий API через `contextBridge`; доступ renderer к операциям main process через IPC. |
| `src/renderer/index.html` | Основной HTML/CSS/JS интерфейс редактора и композитор кадров. |
| `electron/frame-sequence.cjs` | Построение аргументов FFmpeg для raw RGBA и PNG потоков, CFR и аудио. |
| `electron/managed-process.cjs` | Управляемый запуск внешних процессов, прогресс, отмена и завершение. |
| `electron/source-frame-cache.cjs`, `electron/staged-file.cjs` | Ограниченный LRU-кэш кадров и безопасная передача/подготовка исходников порциями. |
| `electron/audio-media.cjs`, `electron/media-timing.cjs` | Анализ аудиопотоков, нормализация и временные метки. |
| `tests/*.test.cjs` | Unit-, интеграционные и регрессионные проверки Node.js/FFmpeg. |

## Проверенные защитные настройки Electron

- `contextIsolation: true`.
- `nodeIntegration: false`.
- `sandbox: true`.
- Preload использует `contextBridge` и выставляет ограниченный API; renderer не получает прямой Node.js доступ.

Эти настройки — хорошая исходная позиция, но сами по себе не заменяют полный аудит IPC-валидации, модели угроз, обработки недоверенных медиафайлов и обновления Electron.

## Зависимости и упаковка

- `package.json` указывает Electron как dev dependency (`^37.2.6`); скрипты `start` и `test` присутствуют.
- `npm test` запускает Node.js test runner.
- В package scripts пока нет сборки установщика/portable-дистрибутива.
- Текущий README требует локально доступные FFmpeg и FFprobe. В этой рабочей конфигурации не заявлена поставка FFmpeg как части приложения.
- Проект пока помечен `private: true`; лицензия репозитория не выбрана. До публичного распространения нужно отдельно зафиксировать точный сценарий поставки FFmpeg, `libx264`, уведомления и обязанности по исходному коду.
- Полный аудит транзитивных лицензий npm-пакетов, CVE и политика обновления зависимостей пока не завершены.

## Экспорт и подтверждённые тесты

- MP4 использует raw RGBA pipe в пределах лимита размера кадра; PNG image2pipe остаётся резервным транспортом и используется для WebM/больших кадров.
- В raw RGBA MP4 предусмотрен H.264 выбор NVENC → AMF → QSV → `libx264`, причём каждый аппаратный вариант проходит короткую runtime-пробу.
- Для выходного видео проверяются метаданные, тайминг кадров, длительность, цветовые теги и аудиопоток при его наличии.
- В тестовой среде: Node.js 22.16.0, npm 10.9.2, FFmpeg/FFprobe 7.1.5.
- Последний локальный результат: `npm test` — 188/188 PASS.
- Syntax check всех CommonJS-файлов в `electron/` и `tests/` пройден.

## Известные ограничения и риски

1. Хост среды разработки не имеет доступного физического GPU для успешного NVENC/QSV кодирования; AMF в установленной сборке FFmpeg отсутствует. Реальные аппаратные экспорты пока не подтверждены.
2. Выбор аппаратного кодировщика подключён к raw RGBA MP4 path; PNG transport path остаётся программным `libx264`.
3. Нет доказанных результатов SSIM/PSNR для эталонных исходников и полноценной серии benchmark на нескольких машинах.
4. GitHub Actions workflow создан, но не запускался в GitHub; Windows/macOS/Linux hosted runners ещё не подтверждены.
5. Полная локализация, installer/portable, Authenticode, SBOM, аудит лицензий и пользовательская документация ещё не реализованы.
6. GUI не запускался в Windows в рамках текущего контейнерного прогона; перед релизом требуется ручной Windows smoke-тест.

2. Подготовить матрицу физического тестирования AMD и Intel.

4. Выполнить профильный benchmark, SSIM/PSNR и тесты 4K60/FHD30 на одной и той же контрольной выборке.
