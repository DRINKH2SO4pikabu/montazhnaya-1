# «Монтажная» beta 3.6.17 — исправление выпадающих списков и профиля проекта

## Назначение обновления

Промежуточный визуально-функциональный патч поверх beta 3.6.16. Основная задача — сделать системные выпадающие списки читаемыми в теме Dark Premium и явно показывать фактический профиль текущего проекта.

## Что изменено

1. Для нативных `select`, `option` и `optgroup` задана тёмная цветовая схема. Текст активных пунктов светлый, выбранный пункт выделяется тёплым оранжевым, отключённые пункты имеют отдельный приглушённый цвет.
2. Сам `select` в отключённом состоянии теперь визуально отличается от активного, но активные списки не приглушаются.
3. В заголовок окна предпросмотра добавлен индикатор текущего профиля: ширина × высота, соотношение сторон и FPS. Он обновляется при смене параметров, открытии/создании проекта и Undo/Redo.
4. При загрузке проекта нестандартные размеры и FPS сохраняются как явно обозначенные пользовательские пункты, а не исчезают из выпадающего списка.
5. При смене соотношения сторон выбирается ближайший пресет по длинной стороне текущего кадра. Например, 1920×1080 при переходе с 16:9 на 9:16 становится 1080×1920, а не сбрасывается до 720×1280.
6. Смена FPS, формата кадра и разрешения не переписывает время клипов, маркеров и позицию курсора. Меняется только профиль последовательности; история Undo/Redo фиксирует изменение.

## Что не менялось

- Монтажные клипы, исходные точки, длительности, дорожки и аудиосвязи.
- Система предпросмотра, композитор и экспорт MP4/WebM.
- Логика импорта, слайд-шоу и сохранения текущего кадра.

## Установка

Пакет `Montazhnaya_Update_3.6.16_to_3.6.17_DarkSelects_R1.zip` предназначен только для beta 3.6.16. Распаковать в отдельную папку и запустить `RUN_PROJECT_SETTINGS_UI_UPDATE_3616_TO_3617_R1.bat`. Установщик проверяет версию и SHA-256, делает резервные копии всех заменяемых файлов и выполняет откат при ошибке.

После установки из корня проекта выполнить `npm.cmd test`. Полный локальный набор beta 3.6.17: **169 тестов, 169 пройдены, 0 ошибок и 0 пропусков**.
