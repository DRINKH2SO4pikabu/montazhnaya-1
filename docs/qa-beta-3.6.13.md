# QA — «Монтажная» beta 3.6.13

## Результат автоматических проверок

- Полный набор: **143/143 passed, 0 failed, 0 cancelled, 0 skipped**.
- Исходная beta 3.6.12: 136 тестов.
- Новые проверки parity: 7 тестов.
- Node.js syntax check встроенного JavaScript Renderer: успешно.
- Syntax check Electron main/preload/managed-process: успешно (эти модули в этом изменении не менялись).

## Что покрыто новыми тестами

1. Все 20 зарегистрированных transition modes возвращают конечные render-state значения в контрольной точке.
2. Wipe, iris, diamond, slide, zoom, blur и spin создают ожидаемые типы состояний.
3. Масштаб дизайна титров проверен для 640×360, 1280×720, 1920×1080 и 3840×2160.
4. Размер шрифта, высота строк и поля титров масштабируются вместе с разрешением.
5. Титры наследуют transition shift, zoom и spin rotation.
6. Preview и local export используют общий композитор, явный sRGB и одинаковые параметры сглаживания.
7. Область применения масок проверена и документирована: переходные маски есть; произвольные пользовательские маски отсутствуют.

## Что не подтверждено этим набором

- Pixel-perfect равенство Chromium decode и FFmpeg decode для каждого исходного кодека/цветового профиля.
- Визуальная проверка всех 20 переходов человеком в Windows/Electron.
- Совпадение HDR/BT.2020/ICC/full-range источников между preview и export.
- Самостоятельные произвольные маски, luma key и rotoscoping — эти инструменты не реализованы.
- Полный end-to-end smoke тест на пользовательской Windows установке в рамках этой сборки.

## Критерий следующей приёмки

На Windows выполнить ручную матрицу проекта и сохранить контрольные кадры предпросмотра и готового MP4/WebM на идентичных timestamps. Для сравнений привести кадры к одинаковому разрешению и цветовому диапазону, рассчитать SSIM/PSNR и зафиксировать объяснимые отличия, вызванные разными декодерами. Нельзя закрывать задачу только по структурным тестам.
