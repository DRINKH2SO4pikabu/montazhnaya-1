# Исправление дублей и порядка слайд-шоу — beta 3.6.3

## Причина

Сборщик beta 3.6.2 читал `project.media` и брал все импортированные фотографии без проверки того, какие из них уже размещены на видеодорожке. Затем создавались новые клипы, при этом существующие клипы пользователя не удалялись. Порядок определялся порядком в медиатеке, а не временными позициями клипов. В результате на таймлайне могли появляться две визуально одинаковые последовательности на разных дорожках, а кадры шли не в задуманном пользователем порядке.

## Поведение beta 3.6.3

1. В окне «Слайд-шоу» появился источник фотографий: конкретная видеодорожка или вся медиатека.
2. По умолчанию выбирается дорожка с наибольшим числом фотоклипов; если пользователь выделил клип на видеодорожке с фотографиями, приоритет получает эта дорожка.
3. Изображения на выбранной дорожке сортируются по `timelineStart` (слева направо). При совпадающих временных позициях сохраняется исходный порядок внутри списка клипов.
4. Существующие клипы переиспользуются. Перестраиваются временные позиции, длительности, переходы, fade и движение камеры; новые ID клипов не создаются.
5. Если выбрана другая целевая видеодорожка, существующие фото-клипы перемещаются туда, а их исходные экземпляры удаляются с прежних видеодорожек.
6. Проверка занятости игнорирует только ID выбранных фотоклипов. Посторонние клипы по-прежнему блокируют сборку, чтобы их не перезаписать.
7. Источник «Вся медиатека» сохраняет прежний режим — создаёт новую последовательность из всех импортированных изображений.
