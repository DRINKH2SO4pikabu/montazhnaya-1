## Автоматические проверки после изменений

- [x] Параметры FFmpeg для `image2pipe`, CFR, H.264 и опционального AAC.
- [x] Последовательные бинарные записи в stdin с ожиданием callback и завершением входного потока.
- [x] Проверка точного количества байтов, принятых дочерним процессом.
- [x] Отмена бинарного потока не вводит текстовую команду `q` в PNG данные.
- [x] Прогресс FFmpeg разбирается и поступает через IPC.
- [x] Выходные PNG-кадры в streaming mode не занимают постоянное место на диске.
- [x] Runtime-оценка сохраняет расходы для исходного frame cache, WAV, временного MP4, конечной копии и резерва.
- [x] Сохранена отдельная проверка лимита кэша исходных кадров.
- [x] Renderer запускает FFmpeg до цикла кадров и отправляет кадры по одному с подтверждением.
- [x] Версии `package.json`, `package-lock.json`, заголовка, бренда и окна «О программе» совпадают.

## Реальная интеграция с FFmpeg/ffprobe 7.1.5

1. 50 PNG кадров, 96×64, 25 FPS, длительность 2 секунды, WAV PCM → MP4 H.264 + AAC. ffprobe подтвердил 50 кадров, 25/1 FPS и длительность 2 секунды.
2. Отмена процесса image2pipe: процесс завершён, `PROCESS_CANCELLED`, текстовая команда в stdin не отправлялась.
3. 3 PNG кадра 3840×2160 при 24 FPS без звука. ffprobe подтвердил 4K, H.264, 3 кадра, 24/1 FPS.
4. После завершения потокового экспорта временный каталог содержит только ожидаемый WAV и итоговый MP4 (либо только MP4 в беззвучном тесте), нумерованные промежуточные PNG отсутствуют.

## Исправление комплектации R2

- Исходный архив beta 3.6.8 не содержал `startFrameSequenceEncoding` в `electron/preload.cjs`.
- Исходный `electron/managed-process.cjs` не поддерживал `writeInput()` / `endInput()` для бинарного stdin.
- R2 включает обе согласованные реализации, сохраняет прежние файлы в резервной копии и проверяет SHA-256 после копирования.
- Чистая симуляция обновления: все 14 файлов применены, версия/Renderer/Main/Preload/ManagedProcess проверены; `npm test` прошёл 101/101.

## Не заявляется как проверенное

- Длительный 4K60 экспорт и реальное 10-минутное видео.
- Полная композиция нескольких видеоисточников в запущенном Electron GUI.
- Windows PowerShell 5.1 установщик.
- Поведение отмены FFmpeg именно под Windows.
- Аудиосинхронизация сложного проекта с большим числом аудиодорожек, встроенным звуком, crossfade и длинной музыкой.
- Исходный кэш PNG более 2 ГиБ: его отдельный лимит остаётся.

Эти проверки остаются обязательной ручной приёмкой до закрытия более широкой задачи длительного/тяжёлого экспорта.
