# Дорожная карта публичного релиза «Монтажной»

Область проекта: локальный видеоредактор Windows x64; цель — надёжная работа на ПК с NVIDIA, AMD, Intel и без аппаратного кодировщика. Ничего из нижеследующего не считается завершённым только по наличию кода: для каждого этапа нужны тесты и подтверждающие артефакты.

| № | Направление | Состояние на beta 3.6.21 | Условие завершения |
|---:|---|---|---|
| 1 | Аудит и стабилизация | Базовая копия 3.6.20 восстановлена из цепочки архивов; 188 тестов beta 3.6.21 проходят; исходная база 3.6.20 имела 180 тестов. Полный аудит лицензий, безопасности и долгов ещё выполняется. | Отчёт по модулям/зависимостям, приоритетный backlog, базовый набор регрессии. |
| 2 | RGBA → FFmpeg | Существует raw RGBA pipe для MP4, PNG pipe оставлен как fallback. На тестовой среде проходят интеграционные проверки CFR, 4K-кадра, BT.709 и AAC. | Повторяемые тесты 4K60 и FHD30, отсутствие потерь/дублей, измерение SSIM/PSNR, допуск битрейта. |

## Защитные правила

1. Перед каждым изменением сохранять контрольную копию затрагиваемых файлов.
2. Не менять legacy-оригинал и не удалять каталоги `backups`.
3. Не считать список encoder-ов подтверждением аппаратной поддержки: нужен реальный runtime encode.
4. Всегда сохранять `libx264` как резервный путь.
5. Проверять не только код возврата FFmpeg, но и реальный файл через FFprobe: потоки, разрешение, FPS, число кадров, длительность, звук и цветовые метаданные.
6. Не выпускать дистрибутив до аудита точной сборки FFmpeg и лицензионных обязательств.
7. Не заявлять аппаратную совместимость без теста на соответствующем физическом устройстве и драйвере.
