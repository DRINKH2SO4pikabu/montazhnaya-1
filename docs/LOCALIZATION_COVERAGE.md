# Montazhnaya — Localization Coverage (3.6.45)

## Reference scope

The English reference dictionary contains 436 Russian source strings. The application offers 34 additional preview variants (24 international and 10 regional script/language variants); Russian and English bring the selectable total to 36.

## International packs

The 24 international preview packs (`de`, `fr`, `es`, `pt-BR`, `it`, `pl`, `uk`, `tr`, `zh-CN`, `zh-TW`, `ja`, `ko`, `ar`, `he`, `hi`, `nl`, `sv`, `fi`, `cs`, `ro`, `el`, `vi`, `id`, `th`) map all 436 reference keys with no English fallback entries. These remain draft translations pending fluent-speaker review.

## Validation

The full Node test suite passed **281 tests with zero failures**. The independent localization quality audit checked all 34 preview locales: 436/436 mapped keys, zero English fallbacks, zero empty translations, zero dynamic-placeholder mismatches, and zero repeated-terminology inconsistencies. CSS parsing also reported zero stylesheet or declaration errors. Runtime loading confirmed 436 mapped keys and zero English fallbacks for all ten regional locale variants.

## Status and limitations

- The regional translations are AI-assisted drafts and have not been approved by fluent native speakers. Uzbek Cyrillic is a transliteration draft and needs independent linguistic translation/review.
- Source-key coverage does not prove that every dynamically assembled renderer string is localized.
- Font stacks are declared for Armenian, Georgian, Cyrillic and other scripts, but target-machine font availability has not been tested on Windows.
- The Electron application was not visually exercised on Windows during this source-code pass. Long-label code-point triage and static CSS checks are available, but actual pixel fit, DPI scaling, installed font fallback, saved language preference, and real Windows language switching still require GUI checks.
- Windows Setup and Portable release packages have not been built in this phase.


## Linguistic and visual quality pass — 3.6.45

- Repeated source phrases that share the same English editing concept are audited for consistent target terminology. In this pass, duplicate “Position” labels were harmonized in Ukrainian, Czech, Kyrgyz and Belarusian.
- All 34 preview locale dictionaries are checked against the 436-key English reference map; dynamic placeholders must match their source keys exactly, and empty values or English fallback entries fail the audit.
- The About screen now uses a localized dialog instead of a Russian-only native alert.
- CSS adds script-specific font fallback stacks and safer wrapping/height constraints for translated menus, tabs, property labels, dialogs, toasts and export controls. RTL reading controls are mirrored without reversing timeline/media geometry or numeric controls.
- These are automated consistency and static layout safeguards. They do not replace review by native speakers or a visual smoke test on Windows at target DPI/scaling levels.
