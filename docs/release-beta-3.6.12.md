# «Монтажная» beta 3.6.12 — совместимость аудио и синхронизация

## Состав обновления

- Анализ аудиопотоков через ffprobe до использования браузерного декодера. Выбирается поток с `disposition.default=1`; при отсутствии такого флага используется первый аудиопоток.
- Политика нормализации предпрослушивания стала консервативнее: ALAC и неизвестные кодеки, многоканальные источники, частоты дискретизации выше 48 кГц и отсутствующие параметры профиля приводятся к единому PCM-профилю.
- Единый профиль нормализации: PCM signed 16-bit little-endian, 48 кГц, stereo.
- Один FFmpeg-нормализатор используется для обычного аудиофайла и для извлечения встроенного аудио видео. Это убирает расхождения между разными наборами фильтров.
- Встроенный аудиопоток выравнивается относительно начала видеопотока. Положительное смещение добавляет начальную тишину; отрицательное отсекает сэмплы, лежащие до начала видео.
- Длительность отделённой аудиодорожки, передаваемая экспортёру, теперь берётся из фактически сформированного WAV, включая добавленную тишину или trim.
- Медиатека показывает профиль источника (кодек, sample rate, число каналов), отметку о WAV-предпрослушивании и явное предупреждение, если предпрослушивание ограничено.
- Для соседних аудиоклипов доступен equal-power crossfade: outgoing `cos`, incoming `sin`. Кривая применяется в realtime preview и OfflineAudioContext, сохраняется в проекте и очищается связанной командой контекстного меню.
- Offline mix объединяет несколько аудиодорожек, встроенный/отделённый звук видео, громкость дорожки и клипа, Fade In/Out и аудиокроссфейды. Если звук видео уже отделён, исходный видеоклип не добавляется повторно в микс.

## Ограничения, которые остаются

- Нормализованный WAV: максимум 512 МиБ.
- WAV-предпрослушивание в Renderer: максимум 96 МиБ.
- Суммарная память декодированных AudioBuffer: максимум 256 МиБ.
- Потоковый аудиомикшер для длинных музыкальных дорожек ещё не реализован. Для очень длинных файлов редактор должен показать понятную ошибку/предупреждение вместо бесконтрольного выделения памяти.
- Выбор альтернативной аудиодорожки внутри многодорожечного контейнера пока автоматический: используется default, иначе первая дорожка. UI выбора дорожки — отдельная будущая задача.
- Реальная приёмка длинного многодорожечного проекта, preview/export и проверка звучания на Windows/Electron должны быть выполнены вручную.

## Установка

Это накопительное обновление для beta 3.6.11. Установщик проверяет исходную версию, проверяет SHA-256 файлов пакета, делает резервную копию заменяемых файлов и выполняет постпроверку. После установки запустите `npm.cmd test` в корне проекта.
