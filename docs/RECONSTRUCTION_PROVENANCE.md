# Рабочая копия Montazhnaya beta 3.6.20

Эта папка собрана локально из предоставленных пользователем архивов:
- исходная beta 3.6.17 (полный архив);
- обновление 3.6.17 → 3.6.18;
- обновление 3.6.18 → 3.6.19;
- обновление 3.6.19 → 3.6.20.

Каждый шаг применялся только после проверки ожидаемой версии `package.json`. Перед перезаписью файлов патча копии исходных файлов сохранены в `backups/reconstruction-before-3.6.18`, `...3.6.19`, `...3.6.20`. Проверка SHA-256 архива 3.6.20 и доступных SHA-256 манифестов патчей пройдена.

Это реконструкция рабочей копии, а не подтверждение корректности всех функций и не публикационный релиз. См. отчёт QA после запуска тестов.
