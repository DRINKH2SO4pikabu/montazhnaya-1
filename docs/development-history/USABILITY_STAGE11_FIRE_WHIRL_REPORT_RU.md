# Montazhnaya — Stage 11: «Огненный вихрь», этап 1 из 3

## Что сделано

Подготовлено изолированное WebGL 2 ядро процедурного перехода «Огненный вихрь».

### Визуальная логика шейдера

1. Две текстуры — уходящий и входящий кадры.
2. Раскрывающаяся радиальная фронтальная граница искажается трёхлепестковой спиралью.
3. Шум деформирует кромку, чтобы она не выглядела геометрически идеальной.
4. По границе формируется горячая оранжево-жёлтая огненная кромка.
5. Поверх добавляются небольшие процедурные искры.
6. Тот же шейдер умеет отдельно вернуть прозрачную grayscale-маску через `uMaskOnly`.

### Техническая основа

- Файл: `src/renderer/effects/fire-whirl-webgl.js`.
- Подключён локально из `src/renderer/index.html`.
- API: `window.MontazhnayaFireWhirl.create(canvas)`.
- `render(fromSource, toSource, { width, height, progress, time, seed, maskOnly })`.
- `dispose()` освобождает текстуры, буфер и программу.
- Разрешение передаётся явно, поэтому ядро не зашито под один размер кадра.
