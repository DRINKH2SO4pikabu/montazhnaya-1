# Montazhnaya Beta 3.6.45 — первый пакет исправлений локализации

## Назначение

Первый технический пакет закрывает наиболее заметные пробелы языковой системы: тексты справки и обучения, интерфейсные системные окна браузерного renderer, синхронизацию выбранного языка с главным процессом Electron и перевод принадлежащих приложению диалогов сохранения/предупреждений.

Это инкрементальный пакет поверх исходного Beta 3.6.45. Исходный архив не изменялся.

## Что изменено

### 1. Расширен английский эталонный fallback

Добавлен `src/renderer/locales/guides-en.js`, подключённый после основного английского словаря и до запуска `i18n.js`.

Пакет содержит 519 дополнительных ключей/соответствий (включая справочные, обучающие, контекстные и системные строки) и покрывает:

- все текстовые описания `UI_HELP_ACTIONS` (короткие обозначения горячих клавиш намеренно остаются без перевода);
- все заполненные тексты `UI_HELP_IDS` для полей, свойств и элементов управления;
- все заголовки, пояснения и советы `BEGINNER_TOUR_STEPS`;
- диалоги создания и переименования маркеров;
- сообщения диагностики, уведомления и динамические сообщения о нехватке места;
- текстовые заголовки, кнопки и названия фильтров app-owned диалогов Electron.

Для остальных предварительных языков эти дополнительные строки используют английский fallback, пока в соответствующем языке нет собственного проверенного перевода. Русская локаль сохраняет исходные русские тексты и не подменяется английским fallback.

### 2. Убран ряд непереводимых системных окон renderer

В `src/renderer/index.html` заменены браузерные `prompt()`, `alert()` и `confirm()` собственными модальными окнами приложения:

- `messageDialog()` — информационное сообщение;
- `textPromptDialog()` — ввод/переименование маркера;
- `confirmDialog()` — подтверждение действия.

Заголовки, подписи, кнопки и сообщения проходят через функцию локализации. Маркеры создаются и переименовываются через асинхронный UI-поток. Сообщения toast также проходят через переводчик.

### 3. Добавлена синхронизация локали с Electron main process

Изменены:

- `src/renderer/i18n.js` — отправляет код активного языка и ограниченный набор строк для main process;
- `electron/preload.cjs` — предоставляет узкий метод `setUiLocale()` через `ipcRenderer.invoke`;
- `electron/main.cjs` — принимает `ui:set-locale`, проверяет доверенный renderer/frame, разрешает язык по списку поддерживаемых локалей и очищает словарь перед использованием.

Для основного процесса добавлен `uiText()` с поддержкой строк-шаблонов и `{placeholder}`. Благодаря этому локализуются принадлежащие приложению заголовки, кнопки и подробности следующих окон:

- сохранение покадровой последовательности;
- сохранение текущего кадра;
- предупреждение о недостатке места перед экспортом;
- подтверждение закрытия проекта с несохранёнными изменениями.

Форматирование размеров файлов для не-русских языков выполняется с помощью `Intl.NumberFormat` и двоичных единиц KiB/MiB/GiB.

### 4. Улучшены атрибуты доступности и fallback

В `src/renderer/i18n.js` к уже поддерживаемым атрибутам добавлены `alt` и `aria-valuetext`.

Английский fallback больше не накладывается на русскую исходную локаль. Для других предварительных локалей английский может использоваться как промежуточный fallback, вместо случайного смешения с русским.

### 5. Добавлены регрессионные тесты

Добавлен `tests/localization-first-packet.test.cjs`. Проверяется:

- порядок загрузки дополнительного словаря;
- покрытие `UI_HELP_ACTIONS`, `UI_HELP_IDS` и всего текста начального обучения;
- отсутствие браузерных `alert/prompt/confirm`;
- связь renderer → preload → main process;
- проверка доверенного отправителя IPC;
- использование локализованных строк в app-owned диалогах Electron;
- перевод динамических сообщений с переменными.

## Известные ограничения первого пакета

1. Этот пакет не является финальной профессиональной редактурой всех 36 языков. Новые справочные и Electron-строки имеют английский эталонный вариант; в остальных языках он используется как fallback до редакторской проверки и перевода.
2. Системные элементы самого Windows file picker (например, штатные подписи кнопок «Сохранить»/«Отмена», навигация по папкам) принадлежат Windows и отображаются на языке ОС. Приложение может локализовать заголовок окна, фильтры и свои сообщения, но не системную оболочку диалога.
3. В проекте остаются узкие контекстные подсказки и динамически составляемые описания вне основных наборов `UI_HELP_ACTIONS`, `UI_HELP_IDS` и `BEGINNER_TOUR_STEPS`. Следующим этапом их следует перевести на постоянные ключи, а не пытаться решать расширением DOM-переводчика.
4. Проверки выполнялись в текущей Node/Linux-среде. Полноценная визуальная приёмка всех 36 локалей, проверка RTL в реальном окне Windows, установка Windows-сборки и тестирование файловых окон на Windows в этом пакете не заявляются.
5. Системные ошибки, приходящие из Windows, FFmpeg и других внешних компонентов, могут содержать внешние диагностические фрагменты. В следующем этапе нужно отделить технические подробности от пользовательского сообщения и локализовать именно последнее.

## Рекомендуемый следующий пакет

1. Инвентаризация оставшихся строк в свойствах, контекстных меню, переходах, медиатеке и динамических состояниях.
2. Перевод оставшихся русских строк на постоянные semantic keys (`timeline.clip.split`, `export.status.completed` и т. п.).
3. Внедрение ICU MessageFormat/`Intl.PluralRules` для множественных форм и `Intl.DateTimeFormat`/`Intl.NumberFormat` для дат, времени, чисел и единиц.
4. Автоматический CI-тест: новая видимая строка без ключа/перевода блокирует сборку.
5. Визуальные снимки интерфейса для длинных строк и RTL, затем редактура каждой локали носителем языка.
