# Montazhnaya Beta 3.6.45 — Fire Whirl Stage 18
## Анимированная миниатюра в библиотеке переходов

### Исходная проблема

В Stage 17 карточка «Огненный вихрь» показывала статичный JPEG-постер. Остальные переходы используют видео-превью при наведении курсора или клавиатурном фокусе. Поэтому визуально карточка Fire Whirl не соответствовала поведению остальных карточек.

### Что изменено

- Карточке `fire-whirl` назначен `previewVideo: "fire-whirl.mp4"`; `previewPoster: "fire-whirl.jpg"` оставлен как постер до запуска видео.
- `assets/transition-previews/fire-whirl.mp4` создан из реального пользовательского экспорта `montazhnaya_20261105_1358(2).mp4`. Взята трёхсекундная часть вокруг перехода, включающая входной план, огненный вихрь и новый план.
- Превью перекодировано в беззвучный H.264, 640×360, 20 fps, 60 кадров, длительность 3,000 секунды; размер файла 283 106 байт.
- `posters/fire-whirl.jpg` заменён кадром из того же исходного MP4, чтобы неподвижное состояние карточки соответствовало видео.
- Используется существующий механизм библиотеки: загрузка видео только при наведении/фокусе, `muted`, `playsinline`, `preload="none"`, один декодируемый ролик одновременно; при уходе курсора видео сбрасывается. Уважает `prefers-reduced-motion`.
- Компактный SVG остаётся только у маркера перехода на таймлайне. Preview-композитор, WebGL-шейдер, длительность клипов, аудио и MP4-экспорт не менялись.

### Фактически проверено

- `ffprobe`: H.264, 640×360, 20/1 FPS, 60 кадров, 3,000 с; аудиопотока нет.
- MP4-файл превью присутствует и меньше 600 КБ — соответствует ограничениям остальных миниатюр.
- Постер получен из того же пользовательского MP4.
- Каталог переходов содержит 21 видео-превью; все 21 MP4 и все 21 постер находятся по ожидаемым путям.
- Целевые тесты библиотеки переходов и CSP: **21/21 PASS**.
- Полный `npm test`: **422/422 PASS**, 0 ошибок и 0 пропусков.
- `npm run qa:locales`: **PASS** — 36 локалей, 0 отсутствующих/пустых ключей, 0 ошибок плейсхолдеров.
- CSP SHA-256 встроенного renderer-скрипта пересчитан после изменения каталога и проверен тестом безопасности.

### Режим воспроизведения

Видео-превью запускается, когда пользователь наводит указатель на карточку «Огненный вихрь» или переводит на неё фокус клавиатурой. При уходе курсора/фокуса ролик останавливается и возвращается к первому кадру. Это то же поведение, что у остальных переходов; постоянного autoplay в фоне нет.

### Ограничения

В текущем окружении проверены файл, метаданные, HTML-разметка и механизм событий. Финальный ручной просмотр анимированной карточки в Windows Electron выполняется после установки Stage 18 на машине пользователя.
