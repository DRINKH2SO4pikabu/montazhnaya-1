# Перетаскивание файлов и последовательность по нумерации — beta 3.6.2

## Что изменено

- Файлы, перетащенные из Проводника Windows непосредственно на видеодорожку или аудиодорожку, импортируются в медиатеку и размещаются на дорожке в точке отпускания.
- При пакетном перетаскивании порядок файлов определяется числовым сравнением имён; неподходящие типы файлов остаются в медиатеке и не размещаются на несовместимой дорожке.
- В панели «Медиа» добавлена команда «Расставить по нумерации». Она собирает изображения и видео с цифрами в имени, сортирует их по числовому порядку, позволяет выбрать видеодорожку, старт от курсора либо с конца дорожки и длительность статичных изображений.
- Автоматическая расстановка ищет свободный непрерывный участок на выбранной дорожке, не перекрывает уже существующие клипы и сохраняет длительность исходного видео.
- Длительность изображений при обычном добавлении не изменилась; переопределение применяется только тогда, когда его передали при автоматической расстановке.

## Проверки

- Добавлены модульные тесты для естественной числовой сортировки и распознавания цифр в названии.
- Проверка реального перетаскивания из Проводника должна быть выполнена в Windows/Electron: браузерный тестовый рантайм не воспроизводит системный drag-and-drop.
