# «Монтажная» beta 3.6.5 — управляемое завершение FFmpeg

## Изменение

Финальное кодирование покадрового MP4 теперь выполняется управляемым дочерним процессом, а не `execFile` с ожиданием до таймаута.

- FFmpeg передаёт прогресс в формате `-progress pipe:1`.
- Главный процесс отправляет обновления в Renderer по IPC.
- Кнопка «Отмена» остаётся доступной на этапе финального кодирования.
- При отмене сначала отправляется команда `q` через stdin FFmpeg.
- Если процесс не закрывается за grace period, применяется принудительное завершение.
- Сессия и временные PNG/WAV не удаляются, пока FFmpeg реально не закрылся.
- Результат отменённого кодирования не проходит верификацию и не копируется в целевой файл.

## Ограничения этой итерации

- GUI-проверка на Windows/Electron ещё не выполнена.
- Проверка MP4 через ffprobe и дополнительный FFmpeg `-f null` пока остаются отдельными синхронными этапами; отмена гарантирована для основного этапа кодирования, а не для каждой диагностической команды.
- Лимит 128 МиБ при передаче исходного видео в Renderer/Main пока остаётся отдельной задачей P0.
- Панель диагностики FFmpeg/ffprobe и проверка свободного места будут выполнены следующими отдельными задачами P0.

## Изменённые файлы

- `electron/managed-process.cjs` — новый универсальный управляемый процесс.
- `electron/main.cjs` — запуск FFmpeg с прогрессом и отменой, безопасное владение сессией.
- `electron/preload.cjs` — узкий IPC-подписчик прогресса.
- `src/renderer/index.html` — отображение прогресса и рабочая кнопка отмены финального кодирования.
- `tests/managed-process.test.cjs` — тесты парсинга прогресса, успешного завершения и graceful cancel.
- `tests/functional-audit.test.cjs` — регрессионные проверки IPC и отмены.

## Проверка

- `node --check electron/main.cjs`
- `node --check electron/preload.cjs`
- `node --check electron/managed-process.cjs`
- `node --test tests/*.test.cjs`

Тесты Node.js не заменяют ручную проверку процесса FFmpeg на Windows.
