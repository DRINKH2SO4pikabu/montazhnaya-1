# QA — Montazhnaya beta 3.6.27

## Цель

Разобрать сообщение о том, что после импорта одного видео в медиатеке появляется отдельная карточка `download.jpg` размером 160×90.

## Подтверждённые выводы по beta 3.6.26

1. `grabThumbnail(videoEl, asset)` создаёт JPEG через Canvas и присваивает data URL в `asset.thumb`.
2. `renderMediaLibrary()` отображает `media.thumb` внутри существующей карточки соответствующего медиаобъекта.
3. `grabThumbnail()` не создаёт `File`, не создаёт отдельный `File` URL, не вызывает `importFiles()` и не добавляет элемент в `project.media`.
4. `importFiles()` создаёт ровно один медиаобъект для каждого элемента полученного `FileList`.
5. При отказе от восстановления автосохранения `checkAutosaveOnStartup()` вызывает `clearAutosave()` и возвращается до вызова `deserializeProject(json)`.

Следовательно, отменённое восстановление автосохранения не объясняет появление отдельной карточки. Также это не прямой результат работы `grabThumbnail()`.

## Изменения beta 3.6.27

- Каждая точка входа импорта передаёт метку источника: `file-picker`, `window-drop`, `timeline-drop`.
- Перед обработкой логируется снимок входного `FileList`: индекс, имя, MIME, размер, lastModified.
- После создания объекта логируется имя исходного файла, имя карточки, kind, размеры, длительность и наличие встроенной миниатюры.
- Итоговый toast перечисляет добавленные имена файлов (до трёх).
- Ни один тип файла автоматически не фильтруется: пользовательские JPG не удаляются и не скрываются.

## Проверки

- `npm test`: 212/212 PASS.
- Проверено, что миниатюра остаётся `asset.thumb` и не становится отдельным медиаобъектом.
- Проверено, что все точки входа маркируют источник импорта.
- Проверено, что отказ от восстановления очищает автосохранение до любого десериализования.
- Проверка аппаратного импорта на Windows ещё не выполнена для beta 3.6.27; требуется повторить импорт одного видео и посмотреть итоговое уведомление.

## Как интерпретировать результат на Windows

- Если уведомление покажет `video.mp4, download.jpg`, Windows передал оба файла в выбранный импорт. Тогда нужно исследовать способ выбора/перетаскивания и не маскировать отдельный файл.
- Если уведомление покажет только `video.mp4`, но отдельная карточка JPG всё равно появится, значит её добавляет другой путь или состояние UI; прислать скриншот и файл журнала с `[IMPORT_DIAGNOSTIC]`.
