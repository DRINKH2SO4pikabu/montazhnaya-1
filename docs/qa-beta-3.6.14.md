# QA — «Монтажная» beta 3.6.14

## Исходная версия

- Основа: полный архив пользователя beta 3.6.13.
- Обнаружено 143 теста до изменений; в загруженном архиве версия 3.6.13 согласована.
- В beta 3.6.14 синхронизированы `package.json`, `package-lock.json` и пользовательские подписи версии.

## Изменённые области

- `src/renderer/index.html`: paused seek tolerance вычисляется по FPS проекта и применяется в видео- и аудио-пути; версия UI обновлена.
- `electron/frame-sequence.cjs`: выходная PNG-последовательность явно преобразуется из full-range RGB в limited-range BT.709 YUV420P; metadata задают `color_range=tv` и `colorspace=bt709`.
- Тесты: кадровая чувствительность paused seek, согласование версий, аргументы FFmpeg и реальные цветовые метаданные/погрешность RGB.

## Проверки

- `node --test tests/*.test.cjs`: 149/149, 0 failed, 0 skipped, 0 cancelled.
- Реальные FFmpeg/ffprobe интеграционные тесты: MP4 H.264/AAC, WebM VP8/Opus 25 FPS, WebM VP9/Opus 60 FPS, 4K MP4 и BT.709 metadata.
- MP4 sample test: тестовая PNG-цветовая заливка кодируется в MP4 и декодируется обратно в RGB; проверяются `color_range=tv`, `color_space=bt709`, MAE ≤ 6 и максимальная ошибка канала ≤ 12. На локальном FFmpeg 7.1.5 exploratory run для плоского цветового образца измерено MAE около 0.67, максимум 1.
- Paused seek tolerance проверяется для 24/25/30/60/120 FPS. На 60 FPS порог меньше четверти длительности кадра.
- В `render-parity.test.cjs` сохраняются проверки всех 20 переходов, масштабирования титров и общего композитора.

## Не выполнено в этой среде

- Не удалось выполнить реальный GUI-прогон Electron/Chromium с визуальным захватом одинаковых кадров предпросмотра и экспорта.
- Не измерялись SSIM/PSNR на сложной реальной сцене с цветокоррекцией и несколькими слоями.
- Не проверялись HDR, Display-P3 и внешние ICC-профили.
- Windows PowerShell 5.1 установщик не выполнялся в этой среде; его фактический запуск и ручной GUI smoke test требуется подтвердить на компьютере пользователя.

## Критерий следующего ручного прогона

Создать контрольный проект с каждым из 20 переходов, титром, цветокоррекцией, Ken Burns и двумя видеослоями. Экспортировать короткие MP4 и WebM. Сопоставить кадры в начале/середине/конце каждого перехода; проверить паузу и покадровую навигацию на 24, 30 и 60 FPS. Зафиксировать видимые отличия и сами экспортированные файлы.
