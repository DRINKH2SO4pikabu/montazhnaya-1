# QA report — Montazhnaya beta 3.6.25

Дата: 2026-11-03

## Исправление

В beta 3.6.24 планировщик окон кэша объявлял локальную переменную `windowSize`, но диагностический объект формировался с shorthand-свойством `windowFrames`. В результате Electron main process выбрасывал `ReferenceError: windowFrames is not defined` при планировании первого окна исходных кадров. Это происходило после проверок FFmpeg/NVENC и NVDEC, но до фактического извлечения первого окна исходника.

В beta 3.6.25 свойство записывается явно: `windowFrames: windowSize`.

Добавлен тест `source-window planning diagnostics reference the active window size`, который проверяет этот участок исходного кода.

## Проверки, выполненные в рабочей среде

- `node --check electron/main.cjs` — PASS.
- `npm test` — 202/202 PASS, 0 FAIL.
- Отдельный синтаксический прогон всех файлов `*.cjs` — PASS.

## Не выполнено

- Не запускался Electron GUI на Windows из этой среды.
- Не выполнялся повторный экспорт на физической GTX 1050 после исправления.
- Работоспособность NVDEC/NVENC в beta 3.6.25 должна быть подтверждена повторным пользовательским экспортом с FFmpeg 8.0.1 API 13.0.

## Ручная проверка на Windows

1. Распаковать beta 3.6.25 в отдельную папку.
2. Выполнить `npm.cmd install`.
3. Запустить `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Start-Montazhnaya-NVENC.ps1`.
4. Открыть тот же исходник 3840×2160, 60 FPS.
5. Выполнить экспорт MP4 1280×720, 30 FPS, 5 Мбит/с.
6. Убедиться, что ошибка `windowFrames is not defined` отсутствует, а журнал содержит `[Оконный кэш исходных кадров] План окна` и `windowFrames: 48` (если оценка кэша и свободного места не требуют уменьшения).
7. Проверить `NVDEC_PROBE_PASS`, выбранный `h264_nvenc`, итоговое число кадров, длительность, FPS, средний битрейт и полное декодирование MP4.

## Откат

Предыдущая beta 3.6.24 не изменялась в пользовательской папке. Для отката достаточно продолжить работу из ранее распакованной папки beta 3.6.24. В исходном проекте сохранена резервная копия изменённых файлов в `backups/windowframes-undefined-3.6.24-pre-3.6.25/`.
