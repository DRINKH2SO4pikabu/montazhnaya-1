## Исправления Stage 6

1. **Верхняя панель.** При минимальной ширине окна 1024 px меню и панель действий больше не сжимаются до переноса текста по отдельным буквам. Для узкой ширины меню остаются в первой строке, а панель действий переносится на следующую; подписи сохраняют `white-space: nowrap`.
2. **Панель воспроизведения.** Элементы управления могут переноситься на дополнительные строки, а таймкод становится компактнее. На всех трёх размерах окна горизонтального переполнения панели не обнаружено.
3. **Пустая медиатека.** Ранее `#mediaList` целиком исключался из DOM-переводчика, чтобы не менять имена пользовательских файлов. Это исключение удалено; индивидуальные `.media-item`, `.media-name`, `.clip-name` и другие пользовательские поля по-прежнему защищены. Пустое состояние теперь локализуется, а имена файлов не переводятся.
4. **Пустая шкала времени.** Статическая русская подсказка заменена на локализуемую формулировку; сводка занятого таймлайна использует `uiCount()` и `uiNumber()`.
5. **Приветственный экран обучения.** Английские строки, не имевшие переводов во всех языках, заменены на канонические фразы, которые уже присутствуют в 36 пакетах. При переключении языка открытая карточка обучения перерисовывается.
6. **Заголовок дорожек.** Для `status.timeline.tracks` добавлены отдельные переводы для 34 дополнительных локалей; заголовок обновляется при переключении языка, а не сохраняет первоначальное английское значение.
7. **Регрессии.** Обновлены устаревшие тесты, которые требовали исключения всего `#mediaList` и предыдущую CSS-схему верхней панели. Добавлены новые проверки приветственного экрана, пустой медиатеки, форматирования таймлайна и семантического заголовка дорожек.

## Ограничения — не считать их пройденными

1. **Подробные семь шагов обучения пока не локализованы для 34 дополнительных языков.** Проверено 21 исходное поле (заголовок, описание и совет каждого шага); для каждого из 34 языков отсутствуют все 21 строка в его локальном словаре, поэтому используется английский fallback из `guides-en.js`. Это видно на контрольном скриншоте `known-issue-finnish-tour-step1-english-fallback.png`. Приветственная карточка уже локализована, но пошаговый тур ещё требует отдельного переводческого пакета.
2. **Это не проверка Windows GUI.** Рендерер запускался в Chromium headless на Linux с реальными HTML/CSS/JS и словарями приложения; узкий Electron bridge `setUiLocale` был замокан. Нативные Windows-диалоги, системные шрифты конкретной версии Windows, Setup/Portable и реальные 125%, 150%, 200% настройки DPI в этой среде не запускались.
3. Проверка шрифтовых стэков подтверждает CSS-выбор профиля и корректную отрисовку символов в имеющемся Chromium-окружении, но не доказывает, что все указанные гарнитуры установлены на каждом Windows-компьютере.
4. Переводы по-прежнему имеют статус machine-assisted draft. Автоматическая геометрическая и функциональная проверка не заменяет редактуру носителями языка.
5. Бренд «Монтажная» намеренно сохраняется как название продукта и не считается непереведённым русским элементом интерфейса.
