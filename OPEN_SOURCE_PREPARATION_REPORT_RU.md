**Дата:** 5 ноября 2026 года
**База:** Montazhnaya Beta 3.6.45 / Stage 19
**Публичная модель:** бесплатные официальные сборки; открытый исходный код.

## Принятые лицензии

- Исходный код приложения и проектная документация — **GPL-3.0-or-later**.
- Логотип и выбранная фирменная графика, 21 Grok-generated демонстрационный ролик, их MP4-превью и постеры — **CC BY 4.0**.
- Сторонние зависимости, Electron/Chromium, FFmpeg и пользовательские файлы сохраняют свои отдельные лицензии и права.

## Что подготовлено

- Создан чистый source tree `Montazhnaya_1` на основе Stage 19, а не устаревшего пользовательского архива Stage 13.
- Добавлены полный текст GPL, `LICENSE_SCOPE.md`, `COPYRIGHT.md`, `ASSET_LICENSE.md`, `ASSET_CREDITS.md`, реестр происхождения медиа, notices, DCO, CONTRIBUTING, SECURITY, privacy notes и GitHub templates.
- Восстановлены 21 MP4-превью переходов, 21 соответствующий постер и исходные фирменные PNG/ICO; в окне «Справка → О программе» раскрыто происхождение материалов и указана CC BY 4.0.
- Указана обязательная атрибуция `Created with Grok`.
- `node_modules`, локальные логи, пользовательские QA-скриншоты/контакт-листы и временные файлы исключены.
- Бинарные тестовые MP4/WAV не распространяются: синтетические примеры генерируются локально скриптом `tools/generate-synthetic-fixtures.cjs`.

## Что остаётся до публичного GitHub push

1. Создать публичный репозиторий `montazhnaya-1` под аккаунтом сопровождающего и указать точный owner/URL в `CITATION.cff`.
2. Включить доступные настройки безопасности GitHub: Dependabot alerts, secret scanning, push protection, private vulnerability reporting и защиту ветки `main`.
3. Закрепить GitHub Actions на проверенных полных commit SHA.
4. Перед push выполнить финальный просмотр staged-файлов и контроль секретов.
