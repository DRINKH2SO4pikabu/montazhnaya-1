## Что остаётся до публичного GitHub push

1. Создать публичный репозиторий `montazhnaya-1` под аккаунтом сопровождающего и указать точный owner/URL в `CITATION.cff`.
2. Включить доступные настройки безопасности GitHub: Dependabot alerts, secret scanning, push protection, private vulnerability reporting и защиту ветки `main`.
3. Закрепить GitHub Actions на проверенных полных commit SHA.
4. Перед push выполнить финальный просмотр staged-файлов и контроль секретов.

## Отдельные задачи перед Setup/Portable и бинарным релизом

- Создать `tools/release-toolchain/package-lock.json` для `electron-builder@26.18.1`.
- Повторить сетевой `npm audit` для root и release-toolchain; прошлый запуск был заблокирован ошибкой `EAI_AGAIN`, это не означает отсутствие уязвимостей.
- Сформировать полный SBOM для release toolchain и Windows-дистрибутива.
- Проверить сохранность Electron/Chromium third-party notices в Setup/Portable.
- Собрать и проверить Setup/Portable на чистой Windows 10/11 x64.
- Дополнить аппаратную матрицу: AMD, Intel, 4K, разные драйверы и CPU fallback. Подтверждённый тест NVIDIA 1080p30 не заменяет эти проверки.
- Не включать FFmpeg/FFprobe в первый бинарный релиз до отдельной проверки точной сборки, лицензии, configure flags, checksum и обязательных notices/исходников.
