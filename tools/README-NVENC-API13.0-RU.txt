ТЕСТ СОВМЕСТИМОГО FFmpeg ДЛЯ NVIDIA GTX 1050 — ИСПРАВЛЕННЫЙ СКРИПТ

1. Замените файл tools\Test-Montazhnaya-NVENC-API13.0.ps1 исправленной версией из комплекта.
2. Откройте PowerShell в корне проекта Montazhnaya_3.6.25 (рядом с package.json).
3. Выполните:
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Test-Montazhnaya-NVENC-API13.0.ps1

Исправления: переменная SHA-256 заранее инициализируется; результат Get-FileHash проверяется отдельно; исходник сохранён в UTF-8 с BOM для Windows PowerShell 5.1 (русские сообщения больше не должны превращаться в «РњРѕ...»); прежние значения FFMPEG_PATH и FFPROBE_PATH восстанавливаются после теста.

Скрипт загружает Gyan FFmpeg 8.0.1 в отдельную временную область, проверяет SHA-256 и проверяет наличие параметров NVENC CBR (`cbr_padding`, `strict_gop`) и запускает реальное аппаратное кодирование с одинаковыми `-b:v` и `-maxrate`. Он не меняет системный PATH, системную папку FFmpeg или драйвер NVIDIA. После smoke-теста запускает beta 3.6.25 с отдельным FFmpeg. Журнал остаётся в корне проекта: beta-3.6.25-nvenc-api13.0.log. Для честного сравнения используй исходный 4K-файл `montazhnaya_20261102_1710.mp4` (3840×2160, 60 FPS), а не предыдущий экспорт 1280×720.

Если проверка параметров или NVENC CBR smoke-тест завершится ошибкой, редактор не будет запущен: это исключает ложный benchmark на CPU fallback. Системный FFmpeg и драйвер не изменяются. Не обновляйте драйвер на основании одного лишь сообщения скрипта.
